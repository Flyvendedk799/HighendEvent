Outlook Setup Instructions

  1. Open Microsoft Outlook
  2. Go to File → Account Settings → Account Settings
  3. Click on "Internet Calendars" tab
  4. Click "New" and paste the feed URL
  5. Click "Add" and give it a name like "Festudlej Bookings"
  6. Click "OK" to save

Feed Features

  • Only shows confirmed bookings (deposit paid)
  • Automatically updates when bookings change
  • Includes customer details and booking info
  • Shows delivery vs pickup status
  • Removes cancelled bookings automatically
